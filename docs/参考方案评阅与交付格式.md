# 参考方案评阅与交付格式

2026-10-19。依据用户放入`example/`的9张图片逐张查看，文件索引见[参考资料目录](../example/README.md)。本文确定建议的设计交付方式，不生成或批准新加工图。

## 参考图最值得借鉴的内容

8张图有同一作者水印，包含立体架体、局部尺寸、鱼缸/型材/过滤清单和板件孔位；另1张为独立材料价格表。暂按两组资料索引，现有图片无法证明是两套完整工程，均没有可编辑CAD源文件。

这组资料把装配、尺寸和零件放在一起表达，很符合本项目需要：

- **立体装配图**看出每根梁、立柱及连接的位置，配合正视/侧视/俯视核对尺寸。
- **零件清单**列清长度、数量、材料、端部加工、螺钉、板件及用途；购买、到货状态可以继续记录。
- **板件详图**包含厚度、孔径、边距及孔距，后续加侧板、门板、洞洞板时有明确接口。
- **分系统整理**：架子、鱼缸、过滤、管路各有清单，再由总装图统一尺寸。

后续本项目还应补：统一零件编号、拆装/爆炸图、关键节点剖面、管件与梁避让、设备装取路径、版本和待确认项。这样图纸能持续细化，每个图中零件也能在清单中找到。

## 参考配置的适用边界

图中架体清单写3030、A6063-T5、攻丝与角码连接，并有轮、侧板、门板和洞洞板；主缸清单为600×600×400，架体清单外形约610×605×760且不含轮。这些属于参考案例自身尺寸，不能按照片缩放成我们的600缸架方案，也不能凭图认定相同节点或型材满足本项目荷载。

过滤资料包含周转箱、生化过滤、滤筒、浮球及止回阀等内容。它们的实际水路、独立应急和故障容量没有完整图示；本项目保留已讨论的主下水、独立应急、蛋分、限量补水和被动停泵容水要求，不能从该清单直接得到本海缸的管件单。图中金额仅为参考截图记录，无报价日期和当前商家核验。

## 推荐的格式组合

建议采用**参数化三维主模型＋同版审阅图册＋加工交换文件＋物料清单**。其中主模型优先考虑FreeCAD；具体工具是本轮建议，尚未成为用户确认或完成的建模成果。

| 文件 | 用途 | 后续怎么用 |
|---|---|---|
| FreeCAD `.FCStd` | 保留零件、尺寸关系、参数和装配位置的主文件 | 改主参数并重算，继续添加面板、支架、托架和管路接口 |
| `.STEP` | 给使用其他CAD软件的商家交换三维实体 | 核对形状、尺寸和装配；同时保留原生主文件以继续参数化设计 |
| `.DXF` | 板件、节点板及孔位的二维几何交换 | 按毫米、1:1导出零件轮廓和孔，另配材料/厚度/公差说明；加工前由商家确认导入 |
| `.PDF`，配PNG预览 | 统一的审阅及询价图册 | 浏览、批注、打印、发商家；保留图号、尺寸、零件编号和版本 |
| `.CSV`，配Markdown清单 | 下料、板材、五金、设备和报价记录 | 同一零件编号贯穿模型、图纸、清单；数量及尺寸由模型提取并核对 |
| `.md` | 需求、设计取舍、变更与验收记录 | 在项目内持续维护，与同版模型/图册互相链接 |

依据：[FreeCAD官方功能说明](https://freecad.github.io/Website/features/)介绍参数化对象、原生FCStd和STEP/DXF等格式支持；[官方原生格式文档](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/File_Format_FCStd.md)说明FCStd保存几何及参数信息；[官方工程制图说明](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/TechDraw_Workbench.md)说明从三维模型生成视图、剖面及标注，并输出PDF/SVG/DXF。后两份为官方归档文档，具体菜单和导出效果仍应按实际安装版核验。本建议不依赖某个插件或收费版本。

## 如何保证以后能按尺寸继续深化

1. **统一总参数**：缸架外长、深、架高、型材截面、板厚、梁位、底缸位置等集中定义；确认值与候选值分开。模型内总参数表作为新版本几何依据，另行导出的JSON仅为该版快照，避免同时手改两份尺寸。
2. **每个零件单独建模并编号**：长梁、深梁、立柱、节点板、台面、底缸板、盘及面板分别保留，不能把全架做成一块不可区分的外壳。设备先用标明来源/状态的占位包络。
3. **尺寸建立关系**：型材净切长按最终拼接方式和外尺寸计算；孔位从明确的零件基准定位。以后改深度，关联梁长和板件按已建约束重算，重新核对孔下避梁和维护空间；没有建关系的地方不能宣称会自动更新。
4. **三种尺寸分开标注**：鱼缸/承重框主体外尺寸、连接件/外挂后的总包络、内部可用净空间。型材净切长另列，避免再把外长600误写成所有构件都切600。
5. **验证一次真实改参**：改一组深度或架高，检查模型重算、关联图纸及清单；再恢复目标尺寸。STEP/DXF重新导入核对关键长度、孔距与单位，不能只检查文件是否存在。
6. **同版导出与变更记录**：主模型、图册、交换件和物料清单使用一致版本；标明评审/询价/已批准加工状态。结构、玻璃支撑及设备实际适配的审核另行记录。

## 下一版图册应有的内容

| 图组 | 内容 |
|---|---|
| 总装 | 完整系统立体图、裸架立体图、正侧俯三视图，尺寸及统一基准 |
| 拆装 | 构件编号和装配/爆炸图、安装顺序、下料表 |
| 节点 | 实际供方截面、连接剖面、孔/攻丝/沉头、紧固件及工具空间 |
| 板件 | 台面、底缸板、接水盘及后续面板各自尺寸与孔位 |
| 联合布局 | 主底缸、泵、蛋分、补水盒、三路管件和维护取出空间 |
| 水路 | 正常运行、停泵、应急下水与相关水位，容水计算引用 |
| 清单 | 统一编号的零件、数量、规格、加工要求、来源及待确认项 |

外长按鱼缸和承重框均600推进；深度与主缸对应，450仍属候选；架高约900、维护优先沿用。约700现场空间用于核对外挂及操作总包络。旧580×430框架及旧下料不进入新版默认值。
