# 防漏与防溢设计要求

状态：需求阶段的设计与验收要求。尚无加工图、容量计算结果或实物测试记录，不代表当前方案已通过安全验证。

## 使用条件和目标

木地板，楼下有邻居。用户将“不漏水”列为重要要求，本项目把防漏、防溢置于最高优先级；同时必须明确，玻璃、粘接、接头、设备和人为操作均存在失效可能，任何家用鱼缸不能承诺绝对零风险。

设计目标：预先分析可识别的故障，优先用水路与容水空间防止溢出，再设置限量、停机、接水和报警，明确各项保护的边界。报警器不能代替结构设计。

## 当前使用方式

- 厨房约1m，水池约2m，已有RO净水器。用户愿意手动搬水，不优化固定供排水管线。
- 换水希望方便从主缸抽出旧水，优先使用临时固定的虹吸管或抽水泵，有人看管。
- 当前不规划RO直连鱼缸或自动换水。自动蒸发补水如采用，使用有限容量容器及故障保护，型号待选。

## 设计要求

| 工况或位置 | 要求 | 设计时的核对内容 |
|---|---|---|
| 停电、关回水泵 | 底缸接住主缸溢流、回水反虹吸及管路排水，并保留余量 | 回水口高度、溢流水位、底缸最高安全水位、管路及未来冷却回路水量 |
| 主下水堵塞 | 独立应急下水能接住设计最大实际回水流量，主缸不越过安全水位 | 不依赖主下水调节阀；独立管路、入口及末端出水均需检查 |
| 共同堵塞或排水不足 | 评估主缸高水位停泵、停补水保护，并核对停机前可能继续输入的水量 | 不能只算回水仓名义体积；需按实际分仓和可抽水量计算，故障后的恢复方式明确 |
| 自动补水失控 | 有独立高水位或超时保护，限量补水，并处理补水管虹吸 | 按补水容器允许最高装水量核算；不能仅依赖一个正常工作的液位探头 |
| 补水失控后停电 | 最大补水量与停泵回流水同时计入底缸余量评估 | 不把两种工况各自的余量重复使用 |
| 缸体与穿缸接头 | 主缸、底缸交制缸商制作；孔位、密封及支撑要求按加工方和接头说明核对 | 不在未经确认的玻璃上自行开孔；缸底支撑、平整和固化要求落实 |
| 管路和软管 | 尽量减少不必要的接头，管路固定，便于检查和拆洗，不让管重拉扯玻璃接头 | 规格、胶粘或螺纹方式、软管固定方式按产品要求，不把所有接口一律当作缠生料带处理 |
| 底柜小漏水 | 底缸、常见接头下方考虑带边接水盘及漏水传感器 | 接水盘实际容量、装入路径、变形与清洁条件；不宣称浅盘能接住整缸破裂泄水 |
| 漏水检测和停机 | 若采用联动，明确实际切断补水泵或回水泵等设备，断网时保护能力及复位逻辑 | “有报警”不等于“能停泵”；停回水泵后仍须能接住回流水，重力泄漏也不会自动消失 |
| 电气与维护 | 插排、控制器固定于适当干燥高位，安排滴水弯；常检查位置从正面可见、可达 | 不把插排放在柜底接水区；未来面板不能遮蔽必要的检查和通风 |

止回阀或防虹吸孔可以作为辅助，但不能替代足够的停泵容水空间。设计应按止回阀不起作用的情况检查回流。

## 容量计算的交付要求

后续详细设计需列出：主缸运行水位及停泵后的水位、回水口位置、溢流区及管路排水量、底缸运行水位、设备排水体积、分仓实际可用余量，以及补水容器最大允许装水量。

矩形水层的估算为 `长(mm) × 深(mm) × 水位差(mm) ÷ 1,000,000 = 水量(L)`。该估算不能代替全部回流计算，实际还需考虑玻璃内尺寸、溢流及管路。

标记运行水位线、底缸最高安全水位和补水容器最高加水线。改变回水口、运行水位、设备、管路或冷水机后，重新核算并测试受影响的工况。

## 淡水联调验收

在受控、可接水的条件下测试并记录，不直接在木地板上制造不可控的溢水场景。

1. 按加工和密封材料要求完成固化，检查静态及运行渗漏。
2. 在设计允许运行水位、配置及流量下测试停泵和恢复供电，记录底缸最高水位。
3. 受控模拟主下水失效，确认应急下水独立排水及主缸水位。
4. 验证高水位、补水超时、限量及防虹吸保护；失控补水容量和复合停电工况先计算，再制定安全模拟方法，不直接盲目放空补水桶。
5. 单独测试漏水检测、声光或远程通知，以及实际设备停机和人工复位。记录断网、断电条件下各项保护是否可用。
6. 按未来日常流程完成一次手动换水，核对管子固定、桶容量、水位标记、补水暂停和恢复顺序。

## 日常换水流程的设计方向

准备已配好的新海水和容量足够的旧水桶 → 暂停补水并按水位需要停相关设备 → 固定临时抽水管抽出旧水，达到预定量立即停止 → 加回新海水 → 恢复循环并核对水位、接头 → 稳定后恢复自动补水。

具体抽水量、停泵顺序和标线随系统设计确认。换水操作时尽量保留漏水监测，避免为减少误报长时间关闭安全功能；如必须暂停，列入恢复清单。
