- 初期开放，后续可加可拆面板；预留安装位置和厚度。当前采用固定底座方向。
- 用户明确希望后加横梁，用于挂插排等附件。请提供可后装附件的槽型材，说明系列、槽口及匹配的后装螺母、螺栓和角码/连接板；预留槽口及工具操作空间，后装面板可拆。轻载附件梁和安装板应能在不拆承重框的条件下安装，具体位置及允许挂载由店家确认。
- 插排、控制器和电源适配器优先固定在可拆的干区安装板上，可连接立柱或附件梁；避开底缸敞口及接头溅水路径，电线留滴水弯，并保留散热及拔插空间。安装板与梁不遮挡底缸、蛋分或泵的取出路径。
- 底缸420×310×460及补水盒65×240×180为布局候选，店家应标内部净空间、正面开口和所有侵入空间的连接件。底缸尺寸可随联合布局修订。
- 顶梁须与主缸真实下水、应急下水、回水接头及工具空间协调；孔位与接头尚未定案。底部承板须有明确支撑。
- 店家按最终主缸、底缸满水及玻璃、砂石、设备等荷载设计，说明载荷依据、支撑与防晃措施。型材截面、连接方式、梁位、节点及脚座由店家提出。
- 分层工作载荷设计输入：上层200kg、下层100kg同时加载，架体、承板和底座自重另外计入。当前上下层使用重量保守估算分别125～145kg、45～55kg，整套落地约195～245kg；上述设计输入须由店家核验。各层承板/梁分别核算，立柱、下框整体及落地支撑核算合计载荷、挠度和防晃，见[分层荷载复核](../research/缸架分层荷载与轮组复核.md)。
- 用户转述带轮方案承重三四百斤（150～200kg），店家建议去轮；此为未取得技术资料的转述值。当前沿用固定底座方向，请店家单独说明去轮后整架的长期工作载荷、是否含自重和允许的上下层分配，不能直接沿用轮组数值。

- 兼顾木地板的承压、防水与隔振，以及接水盘安装；底座变更后同步复核盘和柜内标高。

## 可供店家比较的加强办法

用户询问提高承重的方法。以下为待店家比较的选项，尚未采用新截面或更改总装尺寸：

1. 先确认带轮三四百斤的限制来自轮组、轮座连接还是框架；固定底座另出额定工作载荷及承力路径，不能把去轮视为框架自动达到目标载荷。
2. 如主梁挠度不足，可比较更高刚度的4040真实截面，或局部采用4080承重横梁。4080按80mm方向竖放时核对实际截面性能；上梁增高后要重新核对柜内净高、接头及蛋分取出空间。若上梁从40高增至80高且架顶标高保持900，上梁下缘会降低40mm，当前337头部净高相应变为297，不能只换材料表。
3. 在需要的部位增加承托横梁或中间支撑，缩短承板/横梁的有效跨度。主缸承托和底缸板支撑分别核对，横梁之间的连接须能传递载荷。加中柱会影响前方开口，优先保持底缸装入及设备取出空间；后侧增柱也须核对其实际支持的梁，不能默认整架均匀增载。
4. 采用有负载依据的角码、连接板或节点，核对配套螺母、螺栓、安装孔数、紧固要求及抗滑移能力；连接方式由店家按系统确定，不强制同时叠加所有连接件。
5. 后侧/侧面增加适当斜撑或结构连接，控制侧向变形和防晃；普通饰板不作为结构支撑。斜撑与管路、配电及维护路径协调，不能将防晃改善直接折算成整架承重公斤数。
6. 复核固定脚座或连续底座、调平及木地板承压，确保上下层载荷均有明确落地路径。增加脚数须保证实际接触和载荷分配。

优先让店家比较两套完整方案：其常用4040固定架；满足相同上200kg/下100kg同时工作工况的必要加强版。两套都说明真实截面、梁跨度、连接、挠度及防晃依据，避免只按壁厚或根数比较。品牌材料不能替代本架的结构核验。

依据：[米思米型材负载与挠曲量选型](https://techinfo.misumi.com.cn/exportarticle/article/2522/)、[米思米连接支架及容许负载](https://techinfo.misumi.com.cn/exportarticle/article/2723/?tid=hp_article)。这些厂家资料提供计算和连接选型原则，未证明本店型材、节点或本架承载合格。
