# 溢流、管路和鱼便：概念说明

## 与洗脸池溢水孔的区别

洗脸池通常有底部正常排水口，靠近上沿的孔主要应急。我们拟采用的海缸，表层溢流入口是**正常循环的排水入口**：回水泵不断往主缸送水，水位超过入口就持续流入溢流区，再下到底缸。

溢流区内的主下水承担日常流量；另一根更高的独立应急下水在主下水异常或设计规定的工况下接水。鱼梳入口、主下水和应急下水不是同一个零件。

## 为什么管子不必出现在侧面或背面

水从溢流区内的立管往下，经过缸底玻璃上由缸厂制作的孔和密封穿缸接头，直接进入柜内管路。回水也可以从这一区域穿回主缸，再在缸内转向出水。

因此“缸外侧挂管”不是底滤的必要条件。当前设计目标是下水及回水均在缸架外轮廓内；详细孔位仍须和玻璃、接头、台面及架梁一起核对。

## 鱼便如何处理

| 形态或位置 | 主要去向 | 维护动作 |
|---|---|---|
| 悬浮的鱼便碎屑、残饵颗粒 | 随水流进入溢流区，再到物理过滤 | 取出脏滤棉或过滤篮，真正把截留物移出系统 |
| 沉在底部、石缝里的较重颗粒 | 不保证自行进入表层溢流 | 造景留清洁通道，必要时吹起局部沉积，换水时虹吸带走 |
| 溢流区内沉积 | 可积在管根、角落 | 保留可拆鱼梳/检修盖，停相关设备后刷洗、虹吸；不能做成无法伸工具的死角 |
| 已溶解的污染物 | 不是滤棉能全部拦住的固体 | 依靠生物过程、适用的蛋分及规律维护，不能以“排便口”取代水质管理 |

造浪和回水方向影响颗粒运输，但不能保证全部鱼便自动排净。过滤材料脏后不拿出来，截留物仍留在系统内。

底吸缝、双层溢流板或“三重溢流”可能另有收集底部水的路径，但必须看真实结构及停泵状态。本版不把这类营销名称当作自动排净和防漏证明；以后如采用，要重新核对水道与停泵回流。

## 本项目采用的维护方向

优先简单表层溢流、合适水流、可拆物理过滤和方便虹吸的造景。不为“强排”额外增加一套长期通向外部的排水阀路；用户已愿意人工搬水。
