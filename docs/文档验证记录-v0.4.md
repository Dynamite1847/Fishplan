## 复现

```sh
python3 scripts/generate_v04.py
```

SVG变更后重新渲染对应PNG并查看。独立DXF解析命令在具备`ezdxf`的Python中运行`readfile`及`doc.audit()`，不需要在仓库安装依赖。DXF标注为mm，实际CAD导入仍需核对200节点板校准尺寸，不能依赖软件默认英寸设置。
