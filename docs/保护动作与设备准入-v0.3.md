# 保护动作与设备准入 v0.3

用户明确重视防漏，本文件把“哪个探头、停哪台设备”分开，作为选型和验收依据。没有选定全套控制硬件，也不是市电接线图。

| 场景 | 拟检测位置 | 拟动作 | 核验重点 |
|---|---|---|---|
| 主缸异常高水位 | 主缸水面异常线上 | 停回水与ATO，报警，原因复核后恢复 | 正常波浪不误触，停机延迟的继续送水量可容 |
| 地面/盘内漏水 | 常见管件下方及接水盘低处 | 停回水与ATO；按实际水位停蛋分、加热等 | 停泵后的回流仍可容；重力漏水不会自动停止 |
| ATO高探头 | 回水仓正常线之上 | 已读One 2 SE说明：报警并停ATO泵 | 不能据此宣称同时停回水或检测地板漏水 |
| ATO桶缺水 | 补水泵自身/容器 | 按原厂逻辑停补水并报警 | 只保护补水泵，不是主回水泵的缺水保护 |
| 回水仓过低 | 低于正常、仍高于泵最低浸没 | 停相应水泵及可能露出水面的加热器，报警 | 阈值和复位另定，不能以“热保护”当允许干转 |
| 全屋断电再来电 | 实际供电恢复 | 按定义恢复水路，稳定后ATO工作 | 高水位/漏水故障不能因一次断电被盲目清除 |

## 设备筛选要求

- 说明所售版本的输入电压、允许负载和实际切断对象，不混用115V设备或未核验的转换件。
- 保持本地基本动作，不把互联网通知或云端自动化当唯一保护；断网时现场验证。
- 能分别测试主缸高水位、地面漏水、ATO超时/高探头，记录故障锁定、复位和重新上电行为。
- 断开的设备组、仍保留的设备组由实际故障和水位确定；造浪若仍浸水且不扩大泄漏，可保留交换，不能一概认为关掉所有设备就是最优。
- 不做无说明的自制市电拼装盒。选有明确电气参数和适用说明的成熟控制设备；需要固定配线时交合适人员实施。

## 干区与湿区布置

插排及电源不放接水盘底。候选为右前上方可拆的干区安装板，正面能操作，给线缆滴水弯和应急断电留空间；是否真的干燥要看底缸飞溅、冷凝及日后盖板散热，不仅凭安装高度认定。

Kamoer控制器原说明非防水且对湿度有限制，不能因为是鱼缸设备就塞进潮湿密闭底柜。未来实体面板、风扇和冷水机加入后重新看散热与冷凝。

## 故障后的人工卡

发现异常 → 先避免接触进水的电源 → 在安全位置停相关供电/泵 → 控制仍在输入的水 → 核对底缸回流水位、重力泄漏与地面 → 用桶受控排水 → 查明原因再复位。不给“推走满缸”安排应急步骤。

原厂依据见[One 2 SE核验记录](../research/设备说明核验记录-v0.2.md)及[SICCE说明](https://us.sicce.com/media/wysiwyg/ISTRUZIONI/80N178-J_SICCE_Syncra_Silent_Instruction.pdf)。本表的跨设备停机是本项目待实现要求，不能读成上述厂商产品已自带全部功能。
