# 噪声设计与验收

状态：需求及设计方向，尚未选定设备或实测。更新：2026-10-18。

## 使用场景

鱼缸靠近卧室，家里人偶尔留宿，客厅也可能有人睡觉。用户明确要求控制噪声。

噪声是与防漏、维护便利并列的重要设计目标；防漏及应急排水能力不能为静音让步。尚未约定分贝数，不使用卖家“静音”标签或未经实测的数字承诺睡眠体验。

## 设计方向

| 声源 | 处理方向 | 必须保留的条件 |
|---|---|---|
| 溢流区落水 | 避免不必要的大落差，水位随系统调试 | 仍需预留水位变化、入口及应急排水能力 |
| 下水吸气、咕噜声 | 优先核验主虹吸下水＋独立应急下水的结构，匹配回水量并调节 | 调节阀只用于主下水，不能以关小应急下水换取安静 |
| 底缸落水、冒泡 | 设计合适的出水位置与正常运行水位，避免雨淋式大落差 | 末端位置不能妨碍应急排水、虹吸启动或检修 |
| 回水与造浪泵 | 核对实际运行档位、异响和振动；按设备要求减振并支撑管路 | 保持必要的循环，不靠夜间关掉全部循环解决噪声 |
| 蛋分进气与泵声 | 设备选型时核验，预留进气消音、拆洗和检修条件 | 不堵进气、不把运行需求让位于表面静音 |
| 灯具风扇 | 选择时考虑散热方式及实际声音 | 不关闭必要散热强行降噪 |
| 未来冷水机 | 将压缩机、风扇、启动声和散热位置单独考虑 | 不能假设藏进柜子就安静，不能牺牲散热或占用通道 |
| 架子与后装面板 | 避免松动和共振，面板保持可拆；必要时提前装实体面板 | 洞洞板不作为可靠隔音层，不能为了隔音把柜体完全密闭 |

初期开放架的声音会更直接暴露。先把水声和设备本体声音控制好，再评估是否需要提前装面板；面板不是核心降噪的替代品。

## 验收方式

1. 尽量在安静的夜间环境下记录无设备时的背景声。
2. 单独运行回水、造浪、蛋分及其他实际需要的设备，再全部运行，识别主要声源。
3. 在卧室实际床位、门按日常睡眠方式开闭，以及客厅临时睡位判断听感；记录稳定水流、启停、低频振动和气泡声。
4. 如用手机测量，只作为同一位置和条件下的相对比较，不当作校准仪器或合规检测。
5. 检查恢复供电时能否正常启动、进入稳定状态；应急管启动时的异常水声应保留辨识，不把异常声音简单隐藏。
6. 未来增加冷水机或改面板后复测。记录实际运行设置与仍影响睡眠的声源，再决定整改。
