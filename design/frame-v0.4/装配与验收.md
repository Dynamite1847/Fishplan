# 铝架装配与验收 v0.4

本流程在供方确认截面、节点、板材和底座、缸厂确认玻璃支撑、管孔与梁位后执行；现在可先用纸板/木条做等大空间模型。装玻璃和水后不靠松开主结构件来调整设备布局。

## 1. 工具与到货记录

卷尺、可靠直角尺、长水平尺/平直检具、匹配的六角/沉头批头、供方规定量程的扭矩工具、夹具与防刮软垫。板材钻孔及倒角工具按供方回图准备，不为赶工现场凭感觉钻玻璃或市电接线。

记录15根净切长、成对件长度差、端面垂直度、槽型和螺母啮合。核对16块板四孔坐标、厚度、沉头齐平、毛刺。紧固力矩采用**该系列、该螺纹与节点供应商规定值**；没有值就先补资料，不照抄其他品牌角码扭矩。

## 2. 装配顺序

1. 在平整工作面摆下框：B1/B2为通长梁，B3/4/5/6夹入。B5/B6中心X160/440。提前装入封闭后不能添加的T螺母；其余用供方认可的后装螺母。
2. 内梁B5/B6各端左右角码暂紧，共8套；核对上下表面齐平，角码和螺钉不高出Z40。下框对角线和垂直度按供方公差调整。
3. 安装底板四个防窜夹，必要时翻转空下框操作；固定580×340底板，Y52～392。夹件不把板抬离四深梁，木螺钉不穿板。
4. 放四柱P1～4，装下角外板8块，每角两块；孔按F03镜像、沉头朝外，先定位后按供方顺序紧固。板底不低于Z0。
5. 装上框T1～5，T5中心X350；其两端左右4套角码。装上角外板8块，板顶不高于Z900。检查所有节点、框体对角线及双向垂直，再按规定力矩终紧并记录。
6. **空架**检查全外轮廓、外板和螺钉齐平、底面平整。核对底盘内596×446能容纳含板592×442的框体，名义各侧2余量很小，制造公差必须先在供方回图中闭合；不靠硬掰盘壁强塞。
7. 用等大420×310×460箱体验证前方装入：底先到Z210、顶670，平移越过前平面，再下放到Z63。用305高蛋分整机模型、实际磁座及杯轨迹演练；干装D1/D2/R1及阀/活接，确认不碰梁板。
8. 地面检查后，放600×450承压板并按确认的工法找平，再放接水盘和1厚连续硬隔离条，**将空架整体放入盘**。从这一阶段起不靠整体拖动载水架调整位置。
9. 安装底缸垫与空底缸，放限量ATO容器；架内配线、可更换漏水探头及接水盘观察路径先完成。盘内不能放吸水材料遮住漏水，穿线不穿破盘底。
10. 台面按最终穿缸模板加工、封闭切口；固定台面四夹，不让紧固头凸到玻璃支撑面。缸厂确认平整/满面支撑后再放主缸垫及主缸。安装管路时由管夹承力，不能用硬管把玻璃拉到孔位。
11. 复核所有实测尺寸、整体不超600、必要侧/后间隙及面板未来接口，再进入分阶段淡水与故障联调。未达到供方固化要求不得试水。

## 3. 验收记录与停止条件

| 检查 | 记录 | 不通过时 |
|---|---|---|
| 截面/材料/槽型与已核验型号一致 | 型号、图号、实测米重 | 停止，不用“同是4040”替代 |
| 切长、端面、孔型、沉头 | 供方公差与实测 | 修件或补件，不靠主缸压平 |
| 结构工况与紧固依据 | 供方核验文件/回图、力矩 | 不装水，不自行推缸做破坏试验 |
| 空架平整、对角线、垂直度 | 各面实测和供方允许值 | 重调/修件 |
| 底缸装取、蛋分整机取出 | 等大模型/实物录像或照片 | 调布局，不拆关键加固板维持日常维护 |
| 孔下工具区、台面支撑 | 实际接头和阀干装 | 不钻玻璃/不切台面 |
| 下框/盘底/地面持续承压 | 供方工法、地板条件 | 改承压方案并重算标高 |
| 接水盘实际可用容积 | 定量测到可用线、真实探头/线夹均在位 | 改盘或相应保护，不用空盘8.51L充数 |
| 分阶段加载后的变形 | 按供方/缸厂要求测量 | 停止继续加水，按确认流程排水整改 |

尺寸目标与允许偏差应来自供方和缸厂，尤其是玻璃允许的平整度、挠度和支撑边界。本版没有发明一个通用“误差≤1mm就安全”的验收值。真水联调还需执行[联合容水要求](../联合布局与容水-v0.4.md)及[系统验收](../../验收与维护-v0.2.md)，旧版数值以v0.4替换。

结构、底缸或主缸漏水时先按故障流程停泵/停补水并处置；不通过推满水架、临时加轮或松结构螺钉抢险。
