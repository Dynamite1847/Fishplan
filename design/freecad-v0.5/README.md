## 90厘米的高度口径（2026-10-19核对）

用户看过其他海缸后明确90厘米方向可以接受，本轮重点核对内外尺寸。保持当前模型尺寸，分别标注以下基准：

| 高度项目 | 当前值 | 计算及含义 |
|---|---:|---|
| 裸铝架外高 | 900mm | `FrameHeight`；从下框底到上框顶，含上下各40mm横梁 |
| 上下框之间净高 | 820mm | 900−40−40；节点、角码可能局部侵入 |
| 底缸承板上表面到上梁底 | 802mm | 820−18；扣5mm底缸垫后为797mm |
| 底缸沿到上梁底 | 337mm | 900−40−(40＋18＋5)−460；完整装取仍待验证 |
| 地面到台面上表面 | 940mm | 18mm地面板＋3mm盘底＋1mm隔离＋900mm裸架＋18mm台面；调平增量另计 |
| 地面到主缸顶 | 1343mm | 940＋3mm主缸垫＋400mm主缸；主缸高度仍为候选 |

原生文件内的`FrameHeight=900`已直接核对，与参数快照及上述计算一致。整个正面开口还受节点板约束，不能将820mm直接作为底缸装入窗口。

品牌高度对比须采用同一口径：[Waterbox MARINE X 60.2官方规格](https://waterboxaquariums.com/pages/technical-specifications)明确柜体**外尺寸600×500×900mm**，内部尺寸564×464×764mm；[CADE Reef S2 600官方规格](https://www.cadeaquariums.com/aquariums/classic)列柜体尺寸600×700×900mm。两例的900mm均为柜体外高。我们的900mm为裸架外高，叠层后台面离地940mm，较900mm成品柜高40mm；不能把两者视作相同高度。

后续用户在知悉上述区别后表示可以，按当前架高继续。当前裸架900mm及叠层台面940mm保持，未改动原生几何、图册或下料。深度方面用户偏好紧凑，继续以450mm深化，500mm为备选；60×45品牌底滤实例及比较见[尺寸研究](../../research/60厘米海缸尺寸比较.md)。

## 如何继续改尺寸

用FreeCAD打开原生文件，选树中的“00 参数总表”，在下方数据面板编辑：

| 参数 | 含义 |
|---|---|
| `FrameLength` | 缸架外长，当前600；用户已确认，不随意改 |
| `FrameDepth` | 缸架共同外深，当前450候选 |
| `FrameHeight` | 裸架高，当前900 |
| `TopInnerX` | 上内深梁中心位置，改变后必须重核接头工具区 |
| `TopThickness` / `BottomThickness` | 两块承板厚度，改变后核对标高和取出净高 |
| `PanOverhang` | 盘相对承重框每边外伸，当前15候选 |
| `SumpLength/Depth/Height`、`SumpX/Y` | 底缸外形与位置，改变后重算仓尺寸/容水/装取 |

修改后重算（菜单编辑→刷新/重算，按实际安装版名称），再检查空间。当前模型的长、深、高、板厚、梁位有原生表达式关系；节点四孔可在`NodeSketch`草图中编辑。**设备占位位置、三仓净长、工具圆及实际供应商节点并非全部自动适配任意尺寸。** 改深度后必须核对相关空间，不能仅看模型刷新成功。4040槽口是通用示意，修改型材外包参数不能替代真实截面及节点重设计。

本轮已实际执行深450→470、高900→920的联动测试并恢复；另重新打开保存文件，测试深度联动。以后加面板、灯架或托架，可以继续作为独立零件加入同一总装。

原生文件自带几何、约束与显示状态，打开不依赖项目外自定义代理模块。STEP/PDF/DXF属于导出的当版文件，不随主模型后续修改自行更新。
