# 主缸、溢流和管路 v0.2

状态：向制缸商出图和核验的条件设计，不是玻璃加工单。

![正常循环与应急水路](03-水路与余量-v0.2.png)

## 主缸及接口

主候选600×450×400，备选600×400×400。外长不超过600；实际玻璃尺寸、边框或装饰、垫层和盖板突出件一起核对。玻璃厚度、底板形式、打胶及固化由制缸商确认，本文件不认证8厚可用。

后左设置缸内溢流功能区，主下水、备用下水和回水拟在其底部穿缸。外侧不预设侧挂过滤器、侧排包或外背包。深色背景遮挡管路，鱼梳及顶部检修盖可拆。

溢流占位先按宽约180～220、深约100～140的功能范围出图比较，**不作为下料尺寸**。需要容纳三只接头、立管、手或工具及规定孔距，装不下就扩大或重排，不能压缩玻璃孔边距。

顶部回水在缸内出水，出水口应可固定，位置既服务水面交换也限制停泵反虹吸。不能把可旋转喷嘴随意压深后仍沿用旧回流计算。

## 水路清单

| 编号 | 路径 | 当前设计要求 |
|---|---|---|
| D1 | 主缸溢流区→底缸接水/物理过滤 | 主虹吸下水；可微调阀，手柄正面或左前可达，易拆洗 |
| D2 | 溢流区较高备用入口→底缸安全接水位置 | 独立应急下水，不与D1共用可能被调节阀关闭的段；不依赖滤棉畅通才能排水 |
| R1 | 回水区水泵→主缸溢流区内回水管→缸内出水口 | 管路固定、可拆；回水口高度纳入回流计算 |
| A1 | 有限容器→补水泵→回水区 | 出口固定，防止虹吸；不连自来水或RO压力出水 |
| W1 | 换水时临时管→手提桶 | 日常不留开启的永久外排支路，不额外设置无人值守强排 |

## 管件规格：询价候选，不是已匹配物料

- 两路下水先让同一管件商按**公制管外径d32**方案核验；回水按d20候选，泵接口或阻力需要时比较d25。
- 这里的d是管外径，不能和DN、公称英寸或螺纹规格直接混用。穿缸孔按所选接头的实际说明，而不是按管外径开孔。
- 询价需包括两只下水穿缸接头、一只回水穿缸接头、一只主下水微调阀、必要活接、弯头、固定件及与水泵连接的海水适用软接。
- 主下水阀优先能细调且便于维护的结构。备用下水不设置日常节流阀。
- 上水止回阀列为可选件，若装要能检查和拆洗；停泵核算按止回不起作用处理。
- 材料及密封方法按整套产品说明，不混用不同管制、不随意加入金属转接、不把所有螺纹或胶粘接头都用同一种密封方法。

管径只是本轮候选。应急排水能力、主虹吸启动、实际回水量及噪声都要验证；不以d32这个名称直接宣称满足排水量。

## 正常运行与故障逻辑

1. 回水泵送水，主缸达到堰口运行水位，表层水持续入溢流区。
2. D1排正常流量。调节回水及主下水，使运行稳定，避免无必要的巨大回水量和高落差。
3. D1堵塞时，D2独立承担设计最大实际回水量。此时异常水声可以作为提示，不能为了安静关小D2。
4. 停泵后主缸、溢流区及回水管排出的水全部计入底缸；冷却回路未来加入后重算。
5. 更严重的共同阻塞需由主缸高水位停回水、停补水等经验证的保护处理，同时核对停机前可能继续输入的水量。

## 台面与架梁配合

所有穿缸接头的螺母、密封面、安装工具和活接都要避开型材、角码与中间横梁。不只检查玻璃孔中心点。

台面开孔由缸厂给模板；尽量按实际接头留局部通道，不能随意切掉整块溢流角导致玻璃失去规定支撑。若厂家要求大开口，须重新确认底板与支撑方式。

主缸、台面、架子和管路使用同一版图后才能加工。不能先买成品孔位缸再凭现场凑接头。

## 发给制缸商必须回答的项目

- 确认主缸玻璃、底板、溢流密封及支撑方案。
- 提供三只接头的品牌/型号、孔径、孔距、孔边距、螺母外形和安装余量。
- 给出主下水、应急入口、堰口、主缸运行水位和回水口的高度关系。
- 确认正常、停泵、主下水堵塞以及恢复供电时的预期水路。
- 给出需要的台面模板和下方操作空间，说明管路安装与检修顺序。
- 明确运输、验收、固化及淡水试运行要求。
