接外管前：先查背包两只穿缸件

  1. 主缸在最终承托上摆稳，两只穿缸件按套装说明装好，胶垫平整、孔周干净，接头不顶台面。用匹配且可拆的临时堵头封住两处正常出水口。
  2. 外侧擦干，在孔周、螺母和堵头处分别垫干纸。先加自来水到背包底板上约20～30 mm，观察30～60分钟。
  3. 下鱼梳或内部通道若与主缸连通，水会流进主缸；按实际水道加到覆盖孔周，别把背包当成独立水箱灌满。出现水痕就停加、排水，查胶垫夹砂或歪斜后重装，别一直硬拧。
  4. 初检后排水、拆临时堵头，再按3D装配顺序接外管。所有外管胶接并充分固化后，仍要做完整48小时自来水试水、停泵/复电及应急排水测试，做完全部排掉。少量水初检水压低，运行水位下还要复查。

穿缸件安装原则见gmacreef施工指南；水深、观察时间是本缸局部初检建议。

接管顺序：从缸侧向下，最后接泵

打开可旋转的19步装配图 ↗，每步可单独查看零件；页面下方“已购管件怎么用”列出颜色、安装和备用数量。

  1. 先松装6只直装管夹。底座直接贴顶部型材，两下水各2只，上水前后各1只；管夹承托硬管。
  2. 两下水从背包向下。普通穿缸件→灰活接→透明短管→灰90°，绕竖管轴转向左后，斜管直达接水格上方→第二个90°转下→透明活接→透明尾管。主排斜管中接灰活接＋近黑灰红柄微调阀＋灰活接；应急保持独立无阀。
  3. 上水从两缸口分别向下。复用回水穿缸套装自带弯头，向下接透明活接＋透明管＋透明活接→侧面竖管深灰球阀→灰弯头经顶部管夹收进柜内。前后支路对齐后接灰三通。
  4. 三通继续向下。白＋透明止回阀（箭头向上）→主管深灰球阀→白活接＋透明管＋白活接。最后将泵水平转180°试摆，量裁软接、两端卡箍连接。吸入口净距和软管不折扁按实物检查。
  5. 整套对准后再胶接。确认阀可操作、活接可拆、滤棉和泵/蛋分杯可取，标好承插与朝向，按活接分组件取到缸外胶接。固化后再试水；尾管按实际运行水面定长，主排先取水下20、应急水上10～20。

穿缸件只有玻璃固定螺母，不能松它代替活接。应急要停止出水，先停泵等回流停止；拆穿缸件前排空背包。应急独立无阀的原始指南。

先认清用哪个试剂测什么

要测的用哪个试剂怎么读
NH3沙里发（Salifert）NH3试剂，盒上写 NH4/NH3测的是NH3＋NH4⁺总量。色卡<0.25（最浅那格，本页记作“0”）、0.25、0.5、1、1.5、>2，>2是顶格。颜色落在两格之间，按较高那格记。到>2时测NH3稀释样：1份水加2份RO，读数×3
NO2益尔 NO2 试剂色卡只有0、0.005、0.01、0.025、0.1、0.5（mg/L），0.5是最高一格。颜色和0.5一样深或更深，只说明“0.5或更高”，可能是0.5也可能是5，这时要测稀释样（见下）。所以本页的合格线是0.1，不是0.5
KH、pH益尔 KH、pH 试剂第1天加氯化铵水前测一次当起点，之后每周两次，低于6（pH低于7.8）就换水。KH单位是dKH，直接读数
NO3沙里发 NO3 试剂色卡0、2、5、10、25、50、100（mg/L），从上往下看。和NO2是两盒试剂，但它的药粉是先把NO3变成NO2再显色，水里原有的NO2也会一起显色，所以只在两轮检查通过、NO2 0.1或更低以后测
PO4已买的PO4试剂按盒上单位记，养水期间只记录，不据此换水
盐度盐度计（“汉娜紫铜”）目标：写比重（1.0xx）的那条读1.025；只有‰（千分之，也写ppt）刻度的读33。读一条就行。用法同检疫桶养水页：先滴RO水调到0，再滴海水读

下面说“NH3”，都是指沙里发的读数；说“NO2”，都是指益尔的读数。每次测完记下：日期、时间、读数、加了几克、换了几升水。

开始前：排空自来水、铺砂、加RO水、化盐

  1. 排空、铺砂。自来水试水做完，主缸、背包、底缸的水全部排掉，剩一两升不用管。空缸里先摆稳石头、放窝，再铺洗好的砂（见「砂与虾虎窝」），底缸放棉和砖。
  2. 加RO水、记水量。砂面放一个干净盘子，RO水倒在盘子上慢慢加，用20L桶计数。背包往底缸排水后低档开泵，加到右后格运行线。一共加了几升，就是实际水量V（砂石已在，不用再扣），下面的克数都按V算。例子按V=150L。
  3. 先加约九成盐。主泵开着循环，盐量按配水桶试出来的“20L用了多少盐”÷20×水量算全量，先加其中九成。还没试出来的，按瑞丰袋上1kg配30L起步：150L先加4.8kg（和20L先加650g同比例），测了再补，到1.025通常全量要5.3～5.7kg。分小份加在底缸左后格或中间格有水流的地方，不撒在主缸砂面上，不整堆倒进泵入口。
  4. 等溶清再测。循环到完全溶清（一般几个小时，按海盐说明），测盐度：
    • 低于1.025：150L比重每差0.001，补约210g盐（按配水桶20L每差0.001补28g同比例估）。补完循环一两个小时再测。
    • 1.025：可以用。读到1.025和1.026之间也行。
    • 高于1.026：150L比重每高0.001，抽出约5.5L海水，再加5.5L RO水，循环后再测。
  5. 温度到25℃。加热棒设25℃，温控高温断电设26～27℃。记下最后总共加了多少盐。

以后换水的海水：在20L配水桶里配，每桶20L，盐量照配检疫桶海水时记下的“20L用盐量”（袋上1:30是约667g，到1.025一般要700～760g），测到比重1.025再用。换水量都按下面写的升数取，需要几桶就配几桶。

第1天：加菌、测本底、加氯化铵水

  1. 加菌。科迪按盒上标签，新缸每200L用3支：主缸一次倒3支，摇匀倒在底缸水流经过的地方，主泵保持运行。如果已经装了蛋分，先停4小时再开。
  2. 测NH3、KH、pH，记下来。NH3决定今天加不加（见下）。KH和pH今天不用做什么，记下的数是起点：养水时每加一次NH3，KH会掉一点，以后每周测的时候拿来比，KH从这个数掉到6以下就换水。KH一开始就低于7，或pH低于7.8，先查一下盐和配水，再开始。按NH3的读数决定今天加不加：
    • 0到0.5：照常加（下面第3、4步）。
    • 1或1.5：砂石残留或海盐带了NH3，已经够菌吃，今天不加。明天开始按“之后每天”判断。
    • >2：测NH3稀释样（2mL缸水加4mL RO，读数×3）。稀释样也>2：不正常，换一半水（150L换75L）再测，查砂石有没有冲洗干净；不到>2：今天不加。
  3. 配氯化铵水（和检疫桶同一种，配一瓶用整个养水期）。小杯放秤上归零，称2.0g氯化铵，再加RO水到秤上显示200.0g，搅到完全溶解，分装两只100mL有盖瓶，贴“氯化铵水1%　勿饮”，放阴凉处。主缸用量大，两瓶合计约200g，大约够一次检查加一次补喂；剩的不够这次的克数，先配新的再称。
  4. 加首剂 V×0.382g。按下表查克数（150L是57.3g）。瓶子摇一摇，另一个小杯放秤上归零，从瓶里倒到这个克数，倒在底缸水流处，用一点缸水涮杯子再倒回去。杯里多倒的倒掉，不倒回瓶。称的是溶液，不是干粉。
  5. 确认加对了。循环半小时到一小时后测NH3。原来读0的，应在1到1.5那格（实际约1.3）；原来读0.25或0.5的，会在1.5或>2。仍是0多半没加进去，核对后再补；原来是0、加完到>2，多半称多了，今天不再加，测一次NH3稀释样。

之后每天：同一时间测NH3和NO2，按顺序判断

  1. 先看NH3是不是太高。NH3到>2那格（不是刚加完检查量）：测NH3稀释样（2mL缸水加4mL RO，读数×3）。稀释样也到>2（6以上）：这天不加氯化铵水，换三分之一到一半的水（150L换50～75L），第二天再测，仍高再换。按本页的加量正常走不到这么高，到了多半是称错，先查一下。NO2按下面的规则补氯化铵水，最多到约7，到不了要换水的程度，不用另外测“太高”。稀释样不到>2：今天不加，等它降。
  2. 再看NH3。NH3不是0（包括0.25这种很低的读数）：今天不加，明天再测。这天NO2可以不测，省试剂。
  3. NH3是0了，测NO2（先测原水）：
    • 0.1或更浅：开始做检查（见下一节）。
    • 比0.1深、比0.5浅：今天不加，明天再测。连着3天都在这一档，补一次V×0.382g（150L是57.3g）。
    • 和0.5一样深或更深：再测一次稀释样。稀释样比0.5浅（缸里低于3）：补一次V×0.382g（150L是57.3g）。稀释样也到0.5那格（3或更高）：今天不加，等它降。前一天稀释样还到顶，第二天可以直接测稀释样。

稀释用的RO水先单独测一次NH3和NO2，都是最浅那格才能用。

试剂自检：整个养水期NO2一次都没显过色（NH3降了，NO2却一直是最浅那格），先看益尔试剂有没有过期、受潮。NH3试剂靠第1天加完应读1～1.5来验证。

稀释样怎么测：干净小杯里，用20mL针筒打10mL RO水，再用5mL针筒打2mL缸水，晃匀，再按说明书取样滴药。读出来的数×6。稀释样也到0.5那格，说明缸里有3或更高；比0.5浅，说明低于3。缸的针筒和杯子只给缸用。

  • 每周测两次KH和pH（比如周一、周四）。
    • KH 6或以上、pH 7.8或以上：不用做什么。每加1mg氮/L，KH约掉0.4；首剂、两轮检查加几次补喂，累计常掉4以上，起点8左右的话中途多半要换1～2次水。
    • KH低于6，或pH低于7.8：换约40L配好的海水（150L的四分之一多一点），第二天再测。还低就再换一次。
  • NO3、PO4养水中途不用测。两轮检查通过后各测一次，NO3按下一节决定换多少水。
  • 换水的海水先测到比重1.025、温度接近25℃再加。
  • 水少了只补RO淡水到回水格运行线，不补海水。
  • 之后不用再加科迪。菌长在石头、砂和砖表面，换水换不走；标签上“每换100L水加1支”是厂家维护建议，可以不照做。
  • 养水期间不加Prime，加了以后沙里发NH3读数不准。
  • 养水期间不开珊瑚灯，不放活性炭、除磷料、除氨剂；出现明显黄水、异味时活性炭按安装与开缸（项目文档 03-安装与开缸.md）第6节放。

检查两轮，合格才放动物

  1. NH3是0、NO2 0.1或更浅时，加检查量 V×0.764g（150L是114.6g），记下时间。加完半小时到一小时测，NH3应在>2那格。
  2. 满24小时再测：NH3是0，NO2（原水）0.1或更浅，算通过一轮。没通过，回到上一节每天的判断，不叠加检查量。
  3. 第一轮通过的当天，再加一次检查量，做第二轮，判断方法一样。两轮都通过才算养好。
  4. 停加氯化铵，测一次NO3（色卡0、2、5、10、25、50、100，从上往下看），按读数换水：10或更低，换约10%（15L）就可以接动物；25，换约四分之一（38L）；50，换一半（75L），第二天再测；100，换一半，第二天再测再换。收尾可能要40～100L新海水，提前用20L桶分批配好。
  5. 放进第一只动物（包括螺）以后，就不再加氯化铵，NH3来自喂食和动物排泄。
  6. 从这时起定期换水：每周换1桶20L（约12%），不等指标升高。换之前测一次NO3和KH：NO3连续两周在25或更高，或KH低于7，改成每周2桶；2桶时KH还在往下掉，再买KH补剂。按投喂量估，首批4条每周1桶够；10条鱼到齐后多半要每周2桶。
大概多久快的1周～10天就能通过两轮检查；科迪没起明显作用、菌从头长，多在3～4周。按测出来的结果走：哪天通过两轮，哪天就能放动物，不用凑天数。
  • 一周内接动物：不补氯化铵，保持循环、温盐和补水；接之前测一次NH3和NO2，应仍是0和0.1或更浅。
  • 超过一周还没接动物：每2～3天补一次V×0.382g（和检疫桶同一规则），动物到前1～2天再做一轮检查，通过并按NO3读数换水后再接。
  • 螺和枪虾：放了就停加氯化铵，所以最多比首批鱼早一周放；鱼的日期没定就先不放。

依据：BRS无鱼养水（2ppmNH3-N24小时降到0.2以下）、DrTim厂家快速指南、BioDigest原厂FAQ、Seachem Prime与试剂干扰、EHEIM海水指南：首次可在缸内化盐。V×0.382g对应每升1mg氮，V×0.764g对应2mg氮（2.0g氯化铵配到200.0g的溶液）。KH换水线、补盐估算、等待期补喂为助手建议；补氯化铵水门槛（NO2低于3就补1mg氮/L）、稀释样测法是本项目在BRS/DrTim做法上的调整。
