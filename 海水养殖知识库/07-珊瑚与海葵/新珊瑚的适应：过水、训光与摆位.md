# 新珊瑚的适应：过水、训光与摆位

**结论：**新珊瑚入缸先适应运输水温和水质，再从符合品种需求的较低光照位置开始，逐步调整；水流以珊瑚舒展状态为准。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=622186&page=1#pid6459955)[2](https://tidalgardens.com/articles/tutorials/proper-coral-acclimation-guide.html)

## 具体怎么做

1. **入缸前：**提前准备干净容器和检疫空间，核对珊瑚名称、到货状态、原来光照与缸内水温盐度。珊瑚和鱼的检疫、用药方法不同。[4](https://assets.speakcdn.com/assets/2332/1_rescue_coral_holding_facility_and_propagation_facility_documents_v10-31-24.pdf)
2. **过温过水：**先关珊瑚灯，准备干净小盒；测运输水与目标水的温度、盐度，利用已有测量工具。温盐相近时逐步加入少量目标水，约半小时内完成适应；差异较大时先在独立容器匹配温盐，再渐进调整，避免长途开袋后在污染运输水里拖延。温差约0.6℃以内、盐度差1‰以内是本页操作参考。拿底座、不挤压组织，运输水倒掉。佛州项目接收条件含温差约0.6℃，并非所有珊瑚通用的耐受极限。[4](https://assets.speakcdn.com/assets/2332/1_rescue_coral_holding_facility_and_propagation_facility_documents_v10-31-24.pdf)[2](https://tidalgardens.com/articles/tutorials/proper-coral-acclimation-guide.html)
3. **训光：**先放适宜流量且较低光的稳定位置，或降低灯具输出；每天看开合、褪色和组织，几天至一两周逐步移到目标位置或提高照度。若明显发白、持续紧缩，先检查光照、水流和水质，不要继续升光。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=622186&page=1#pid6459955)[2](https://tidalgardens.com/articles/tutorials/proper-coral-acclimation-guide.html)
4. **固定和留空：**确认展开后与邻近珊瑚有生长空间，底座固定牢；避免造浪长期直吹组织，定期清理落在表面的砂。每周拍同角度照片对比。[4](https://assets.speakcdn.com/assets/2332/1_rescue_coral_holding_facility_and_propagation_facility_documents_v10-31-24.pdf)

**处理纽扣及附着物时：**拿底座，戴手套和护目镜，防护细节见[常见软体珊瑚](%E5%B8%B8%E8%A7%81%E8%BD%AF%E4%BD%93%E7%8F%8A%E7%91%9A%EF%BC%9A%E9%80%89%E8%B4%AD%E3%80%81%E6%91%86%E4%BD%8D%E5%92%8C%E6%97%A5%E5%B8%B8%E8%A7%82%E5%AF%9F.md)。[5](https://www.cdc.gov/mmwr/preview/mmwrhtml/mm6431a4.htm)

## 入缸检查、浸浴与漂洗

2026-11-05补充。当前未安排独立珊瑚观察缸；助手建议本阶段先准备独立容器检查、适用浸浴、干净海水漂洗及直接入主缸的路线。鱼检疫桶继续专用，不能把珊瑚按鱼的药物或时间表处理。若选购时出现虫卵、持续掉肉或明显病灶，暂停直接入主缸，先单独处理或退货。

1. **提前分3只容器：**适应／检查、浸浴、漂洗；以本批最大个体能完全浸没且不碰壁为准。备同温同盐干净海水及专用针筒；一次少量处理，不将会互蜇的不同珊瑚挤在同一盒。
2. **白光检查基座及背面：**纽扣看裸鳃类与卵圈；Montipora看底面、边缘小型白色裸鳃类及卵；石珊瑚看咬痕、露骨、垃圾海葵及附着小蟹。底座可安全更换时再更换，不为去底座强撕活组织。拍照记录疑似物，扁跳虾等不一概当害虫。[6](https://tidalgardens.com/articles/coral-care-articles/pests.html)
3. **按产品与物种选择浸浴：**先确认标签适用软／硬珊瑚、剂量、接触时间和是否要求充氧／搅动。药液在独立容器配置，不进主缸；不凭颜色把家用碘伏、碘制剂和除虫浸浴剂互相替代。例如Seachem Reef Dip是含碘消毒产品，原厂强调缸外使用；它的用途不能扩写成包治所有害虫。[7](https://www.seachem.com/reef-dip.php)
4. **漂洗后再入缸：**用干净同温同盐海水带走残液及掉落物，适应水、浸浴水、漂洗水全部倒掉。按较低光与合适间距暂放；第1周每天检查开合、组织和新出现的虫卵，之后仍定期看背面。卵及部分害虫可能躲过浸浴，后续见虫就取出处理，不因浸过一次就写“检疫完成”。[6](https://tidalgardens.com/articles/coral-care-articles/pests.html)

上述路线减少部分搭车生物的引入，仍可能将虫卵或鱼病病原带入主缸；对无鱼观察的需求须与现有全鱼检疫路线分开判断。OATA提到独立观察的价值，但其至少一周建议也不能当成清除所有病原的保证。[8](https://ornamentalfish.org/what-we-do/advice-information/care-sheets/corals/how-to-look-after-coral-polyps/)

## 训光与水流补充

运输前后的光照可能差很多，突然放到强光下会伤珊瑚。先降低照明强度或放在较暗位置，再按开合状态逐步增加。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=622186&page=1#pid6459955)[2](https://tidalgardens.com/articles/tutorials/proper-coral-acclimation-guide.html)

造流要照顾上、中、下各层与岩石背后，避免长期直吹组织或让碎屑沉积；珊瑚放好后看它是否舒展、表面是否积屑，再调泵的位置。[3](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=728843&page=1#pid7231188)
