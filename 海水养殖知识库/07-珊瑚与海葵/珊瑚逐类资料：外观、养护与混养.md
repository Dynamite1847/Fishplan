# 珊瑚逐类资料：外观、养护与混养

**本页把39类候选展开为可逐项比较的资料：先认外观，再看光流、喂食、长大占位与购买检查。**它们是宽候选，未等于39种采购清单；本缸采用数量只在[方案](../../05-缸体与设备方案.md)维护。2026-11-05整理。

先看[外观照片与候选概览](珊瑚怎么选：认识种类与本缸候选.md)；具体成功与失败经过见[实养记录](珊瑚实养记录：成功、失败与本缸取舍.md)。PAR数字是所引养殖来源的参考起点，不能直接换成灯具百分比；本缸摆位为助手建议。价格尚未核到上海同规格实物，暂不填数。

## 软体方向

### 1．普通菇

**鉴别范围：**Discosoma spp.。**本缸排序：**先看。

平圆盘，常见条纹、斑点和纯色；与表面长毛的毛菇、珠粒突起的虎耳分开。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 偏低光开始适应，别因追蓝光荧光色直接上高位。 |
| 水流 | 柔和间接流，能舒展且不被掀翻。 |
| 喂食 | 本缸有鱼投喂，先不另开大剂量珊瑚粮；是否接食逐个观察。 |
| 长大后的空间 | 会移动、留足繁殖；相连石面会使后续控制位置困难。 |
| 混养与攻击 | 组织接触可能损伤邻居；与未来Acropora区分开。 |
| 选购检查 | 看附着是否牢、口盘完整，拒收正在散烂或游离漂浮的个体。 |
| 常见问题 | 伸长追光、长期缩小或脱离基座时，先核光流和近期变化；不凭一个动作定病因。 |
| 本缸安排 | 适合低位补红蓝色，先放可取小石，给清洁螺和海胆碰触留固定余量。 |

依据：[Tidal Gardens：Discosoma养护](https://tidalgardens.com/articles/coral-care-articles/discosoma-mushroom-coral-care.html)；[Tidal Gardens：攻击与摆位](https://tidalgardens.com/articles/coral-care-articles/coral-aggression-placement.html)。

实养对应：[菇与SPS：离开原位置之后的接触损伤](https://www.reef2reef.com/threads/sps-vs-mushrooms.802677/)。具体作者、时长与适用边界见实养记录页。

### 2．毛菇

**鉴别范围：**Rhodactis spp.。**本缸排序：**先看。

盘面突起较粗，似毛或颗粒；商品“气泡”“象耳”不能代替种与体型确认。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 低至中光，从原缸条件缓慢适应。 |
| 水流 | 柔和至中等间接流，避免肉盘被长期掀折。 |
| 喂食 | 若能吞食可试少量适口碎肉，未吞完及时移走；不以包住食物等同成功消化。 |
| 长大后的空间 | 同属大小差别大，大型个体会占整个平台。 |
| 混养与攻击 | 触碰邻居可能灼伤；巨型类型的捕食风险需独立核实，不能套普通小菇。 |
| 选购检查 | 问全展开直径、母株大小及附着时间，不按昂贵品系名判断易养程度。 |
| 常见问题 | 脱落漂移会将接触风险带到原摆位之外。 |
| 本缸安排 | 保留普通小型款，先与普通菇按颜色和纹理比较。 |

依据：[Tidal Gardens：Rhodactis养护](https://tidalgardens.com/articles/coral-care-articles/rhodactis-mushroom-coral-care.html)；[Tidal Gardens：攻击与摆位](https://tidalgardens.com/articles/coral-care-articles/coral-aggression-placement.html)。

实养对应：[菇与SPS：离开原位置之后的接触损伤](https://www.reef2reef.com/threads/sps-vs-mushrooms.802677/)。具体作者、时长与适用边界见实养记录页。

### 3．虎耳

**鉴别范围：**Ricordea florida / R. yuma。**本缸排序：**条件候选。

口盘密布圆突起；两种虎耳不应合成一种饲养结论，商品名常混用。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 低至中光逐步训光，养殖商记录yuma对变化更敏感。 |
| 水流 | 柔和间接流，保持附着小石稳定。 |
| 喂食 | 可少量尝试适口细肉，观察实际吞咽；闭合本身不足以证明接食。 |
| 长大后的空间 | 慢慢形成多头群；先留移动和分裂空间。 |
| 混养与攻击 | 不能紧贴纽扣或SPS，位置被铺满后可能受挤压。 |
| 选购检查 | 优先问清florida或yuma、养定时长，完整附着的普通款便于起步。 |
| 常见问题 | 持续张口、溶解和脱附需查到货伤及近期变化，避免天天换位。 |
| 本缸安排 | 审美保留；初次优先比较养定florida，单独可取小石。 |

依据：[Tidal Gardens：Ricordea养护](https://tidalgardens.com/articles/coral-care-articles/ricordea-mushroom-coral-care.html)。

### 4．纽扣

**鉴别范围：**Zoanthus等纽扣类，具体属种另核。**本缸排序：**先看。

一颗颗圆形彩色口盘；商品花名主要说明品系外观，不能当物种名。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 不同品系对光和发色反应不同，参照原缸并逐步适应。 |
| 水流 | 间接水流带走基部积屑，不让整簇被吹闭。 |
| 喂食 | 先利用本缸鱼粮输入，不为增头数大量撒粉。 |
| 长大后的空间 | 沿石面铺开；快长普通款可能包围较慢品系。 |
| 混养与攻击 | 不同纽扣也会争空间；操作可能涉及palytoxin，佩手套护目镜，禁止热水煮刷或制造气溶胶。 |
| 选购检查 | 核健康开口头数、底座、可疑螺和卵；白光确认真实底色。 |
| 常见问题 | 持续闭合可涉及积污、虫害、啄食或变化，不能一律按缺碘补药。 |
| 本缸安排 | 普通养定款可首批，放可取岛石；小型仙入缸后加看重复啄食。 |

依据：[Tidal Gardens：Zoanthus养护](https://tidalgardens.com/articles/coral-care-articles/zoanthus-coral-care.html)；[Tidal Gardens：珊瑚虫害](https://tidalgardens.com/articles/coral-care-articles/pests.html)；[LiveAquaria：蓝闪电](https://www.liveaquaria.com/products/coral-beauty-angelfish)。

### 5．花环／伞形皮革

**鉴别范围：**Sarcophyton spp.。**本缸排序：**先看。

伞盖上伸细小水螅体，冠面和伸展触手都应看；不能靠“澳洲”标签断定种或难度。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 逐步适应中等光区；不同来源和种有差异。 |
| 水流 | 有通流带走蜕膜，避免冠面长期积屑。 |
| 喂食 | 光合与水中营养共同供给；本缸先利用常规喂鱼输入，额外微食按状态试。 |
| 长大后的空间 | 冠幅可能超过30cm，60cm缸需预留修剪与下层采光。 |
| 混养与攻击 | 可能影响相邻硬珊瑚，保持距离及正常活性炭维护；不能保证炭消除全部作用。 |
| 选购检查 | 看基部牢固无腐烂、冠面完整；只看缩着的一张图难判断状态。 |
| 常见问题 | 蜕膜期可能暂闭；软烂、组织脱落或持续恶化需另外检查。 |
| 本缸安排 | 适合一块作立体主景，首批选小株；不同时放多块大冠盖。 |

依据：[OATA：软珊瑚养护](https://ornamentalfish.org/what-we-do/advice-information/care-sheets/corals/how-to-look-after-soft-corals/)；[Chang等：Sarcophyton glaucum养殖系统研究（2020）](https://pmc.ncbi.nlm.nih.gov/articles/PMC7678846/)。

### 6．丁香

**鉴别范围：**Clavularia spp.。**本缸排序：**先看。

八条羽状触手，沿走茎铺开；与十二触手、有硬骨的茉莉Alveopora分开。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 来源约50～100 PAR供起步参考，仍需按实物适应。 |
| 水流 | 基部走茎通流，带走积屑而不吹倒花头。 |
| 喂食 | 本缸先不专门大量补粉，避免食物落在走茎间。 |
| 长大后的空间 | 通过走茎扩大，连接主景后较难取净。 |
| 混养与攻击 | 会挤占慢长邻居的附着面；独立小岛仍需看跨接。 |
| 选购检查 | 缩回视频要看基部是否为走茎；拒绝只靠店名把“茉莉”当丁香。 |
| 常见问题 | 不开先查积屑、藻覆盖、啄食与新缸变化。 |
| 本缸安排 | 小岛摆位后可作为柔软花朵外观候选，替换首批某一块。 |

依据：[Tidal Gardens：Clavularia养护](https://tidalgardens.com/articles/coral-care-articles/clove-polyp-coral-care.html)；[水族名录：茉莉／流星的名称对应](https://aquaml.com/s/Alveopora.html)。

### 7．八爪／脉动类

**鉴别范围：**Xenia等；按实际商品再核属。**本缸排序：**条件候选。

枝顶如小手，有些有节律开合；不能把所有类似珊瑚都认成同一种八爪。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 按来源及同类养护逐步适应，脉动强弱不能单独当光照标尺。 |
| 水流 | 给全丛温和摆动和基部通流，避免持续压倒。 |
| 喂食 | 不把脉动当喂食成功证据；先跟踪本缸常规营养输入。 |
| 长大后的空间 | 可能快速繁殖，控制重点是周边新株和连接石面。 |
| 混养与攻击 | 不会因没有长攻击触手就没有占地竞争。 |
| 选购检查 | 看基部组织、养定与新生长记录；脉动视频供审美参考。 |
| 常见问题 | 不脉动不等于将死；高温、盐度变化或退肉要结合其他指标。 |
| 本缸安排 | 喜欢动态可选小株，但给可取独立位置，保留后续清理余地。 |

依据：[OATA：软珊瑚养护](https://ornamentalfish.org/what-we-do/advice-information/care-sheets/corals/how-to-look-after-soft-corals/)。

### 8．草皮GSP

**鉴别范围：**Green star polyps商品组。**本缸排序：**本缸原定不买。

荧光绿触手铺成草毯，基部常为连续附着层；商品俗名需看实物。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 按养殖来源适应，外观绿色不意味着只能高光。 |
| 水流 | 保持毯面通流，防积屑和藻盖。 |
| 喂食 | 利用常规系统营养，不为铺得快额外大量加粮。 |
| 长大后的空间 | 会沿相接表面蔓延，玻璃和主石上的控制成本不同。 |
| 混养与攻击 | 主要矛盾是覆盖和抢光，独立石也需定期检查连接处。 |
| 选购检查 | 买时看活毯边缘、基座藻害，别只数伸出的绿触手。 |
| 常见问题 | 短期闭合先查变化和积污；不将其当专用水质试纸。 |
| 本缸安排 | 保留认识条目，沿用用户原定不买的安排。 |

依据：[Tidal Gardens：草皮实物与养护](https://tidalgardens.com/stock-green-star-polyps.html)；[OATA：软珊瑚养护](https://ornamentalfish.org/what-we-do/advice-information/care-sheets/corals/how-to-look-after-soft-corals/)。

### 9．手指皮革

**鉴别范围：**Lobophytum spp.。**本缸排序：**先看。

厚实叶掌或指状凸起；小株与其他皮革可能难凭外观辨到种。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 商家列中至高光，仍从原条件渐适应。 |
| 水流 | 中至强间接通流，让分枝间不积屑。 |
| 喂食 | 可利用光合与水中细食，本缸先不单独增加补剂和大量珊瑚粮。 |
| 长大后的空间 | 横向肉叶会扩展并遮住下方。 |
| 混养与攻击 | 留与石珊瑚的间隔，混养同时看邻居是否持续受影响。 |
| 选购检查 | 看附着与组织完整度，别靠黄绿颜色或产地名判断已养定。 |
| 常见问题 | 蜕膜和闭合需结合组织状态，不按一天不开就搬位。 |
| 本缸安排 | 与伞形皮革作造型二选一参考，优先小株。 |

### 10．肯尼亚树

**鉴别范围：**Capnella spp.。**本缸排序：**条件候选。

像小树或菜花，常见棕粉色；与亮色非光合软珊瑚分开。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 商家列中至高光，可依据原缸缓慢适应。 |
| 水流 | 中至强间歇水流，枝间能换水。 |
| 喂食 | 共生藻供部分营养，细食可补；本缸先利用常规喂鱼输入。 |
| 长大后的空间 | 养定后可较快长大，掉落分枝也可能重新附着。 |
| 混养与攻击 | 孤岛可方便管理母株，但不能保证接住所有碎枝。 |
| 选购检查 | 选附着牢、有生长记录的小株，不为填满空景买大丛。 |
| 常见问题 | 新附着株要早发现；不能用水质归零或盲补碘锶促长。 |
| 本缸安排 | 适合喜欢自然树形且愿定期清理的人，原6块之外不自动追加。 |

依据：[LiveAquaria：肯尼亚树](https://www.liveaquaria.com/products/kenya-tree-coral)；[OATA：软珊瑚养护](https://ornamentalfish.org/what-we-do/advice-information/care-sheets/corals/how-to-look-after-soft-corals/)。

### 11．光合细枝海扇候选

**鉴别范围：**Pinnigorgia flava（ORA Grube’s品系）。**本缸排序：**条件候选。

细枝棕至粉色八放珊瑚；光合海扇和艳红非光合海扇不可只凭“海扇”混买。

| 比较项 | 具体内容 |
|---|---|
| 光照 | 先核具体株来源与原缸光区，当前资料不足以给该类统一PAR。 |
| 水流 | 布置能让分枝间通流、不被持续压折的位置；具体强度需向供货者核。 |

## 比较时不要混用的字段

- **触手数与骨架：**丁香八条羽状触手、走茎式；茉莉Alveopora通常十二触手、有骨；单苞Goniopora通常二十四触手。管风琴是有钙质管骨的八放珊瑚，因此“有骨／没骨”不足以分清所有水族组。
- **生长与发色：**持续增头、包基、边缘增长与颜色好看分别观察；蓝光照片不能证明白光颜色，开几天也不等于长期养成。
- **安全与间距：**未提供每类统一毫米安全线；按实际全开边缘、夜间攻击及长大后的遮光调整。小型仙啄食不能用一个确定勾选覆盖所有个体。
- **报价与规格：**分枝LPS看成熟头、芽头与养定；纽扣看健康头数；菇看展开尺寸与附着；脑类看活肉范围、损伤及全开大小。没有同一规格的报价不做价格排序。
