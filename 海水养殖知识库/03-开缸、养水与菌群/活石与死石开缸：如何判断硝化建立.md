# 活石与死石开缸：如何判断硝化建立

**结论：**成熟活石可能带入菌群，干石需要接种微生物并提供NH3来源。两者都按NH3和NO2检测结果安排生物入缸。循环建立通常需要数周。[2](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=644885&page=1#pid6673260)[4](https://ask.ifas.ufl.edu/publication/FA099/pdf)[5](https://ask.ifas.ufl.edu/publication/FA031/pdf)

## 先把系统拼起来

1. 主缸摆好稳定岩石，接通主泵和溢流。底缸给蛋分、物理过滤和维护留出空间。岩石周边留出能清洁、能过水的位置。[13](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394711)[16](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=602217&page=1#pid6316930)
2. 蛋分按说明书的工作水深安装，出口和杯体留拆装空间。造流朝水面和岩石周边，不直吹珊瑚。[19](https://www.mdpi.com/2673-5636/4/4/52)
3. 这套做法以岩石生物膜、蛋分和水流为核心（常称“柏林系统”）。强水流把碎屑带到蛋分和滤棉，再定期取走。藻缸、吸附剂是可选补充。[12](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394709)[14](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394712)[15](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=3#pid395419)
4. 鱼会直接排出NH3，所以生物过滤要按实际NH3负荷养成。蛋分只能排出部分有机物，不能替代硝化。[12](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394709)[5](https://ask.ifas.ufl.edu/publication/FA031/pdf)

日常排污和滤棉处理见[滤棉、生物滤材与活性炭](../05-%E8%BF%87%E6%BB%A4%E4%B8%8E%E8%90%A5%E5%85%BB%E7%9B%90%E7%AE%A1%E7%90%86/%E6%BB%A4%E6%A3%89%E3%80%81%E7%94%9F%E7%89%A9%E6%BB%A4%E6%9D%90%E4%B8%8E%E6%B4%BB%E6%80%A7%E7%82%AD.md)。

## 无动物开缸：具体怎么做

**适用：无鱼、无虾螺、无珊瑚的海水缸。**

1. 注入合格淡水并化盐，开启循环和加热。盐完全溶解、温盐稳定后，放入洗净的干石和砂。本缸目标比重1.025（约33‰）：盐度计读比重那条到1.025，或读‰那条到33，固定读同一条。[7](https://assets.speakcdn.com/assets/2332/1_rescue_coral_holding_facility_and_propagation_facility_documents_v10-31-24.pdf)
2. **先测本底：**加氯化铵水前用沙里发NH3试剂测一次，同时测pH、KH。沙里发NH3色卡为<0.25（最浅格，记作0）、0.25、0.5、1、1.5、>2（顶格>2）。读0～0.5：照常加；1或1.5：当天不加，明天按第4步判断；>2：测稀释样（1份缸水加2份RO，读数×3），稀释样也>2属异常，先查水源、试剂，再换一半水。
3. 按菌剂标签接种，保持水流和供氧。NH3来源用浓度明确的鱼缸用氯化铵，按**实际水量**计算，一次加足首剂，混合30～60分钟测一次；读数远高于预期就停加，复核剂量、试剂单位和实际水量，当天不追着颜色补。**本缸做法：**科迪BioDigest按实物标签（新缸每200 L 3支）：主缸第1天3支，检疫桶1支，养成后不再常规添加；氯化铵水首剂主缸V×0.382 g、检疫桶20 L加7.6 g。无鱼养水期间不加Prime或其他除氨剂。[22](https://www.bulkreefsupply.com/content/post/brstv-product-spotlight-dr-tims-one-and-only)[8](https://www.drtimsaquatics.com/resources/library/quick-guide-to-fishless-cycling-with-one-and-only/)[20](https://ask.ifas.ufl.edu/publication/4H433/pdf)
4. 每天测并记录NH3＋NH4⁺总量和NO2：NH3用沙里发（测NH3＋NH4⁺总量，色卡最浅格为0），NO2用益尔（色卡0、0.005、0.01、0.025、0.1、0.5 mg/L，0.5是顶格：和0.5一样深或更深只说明“0.5或更高”）。原水到顶时测稀释样：1份缸水加5份RO水（例如2 mL加10 mL）混匀后测，读数×6。其他试剂显示NH3-N、NH4或NO2-N时，按各自单位读取。每天先看NH3，再看NO2：
   - NH3不是0色：不加氯化铵水，明天再测；当天NO2可不测。
   - NH3 0色、益尔NO2原水≤0.1：开始第5步的检查。
   - NH3 0色、原水比0.1深、比0.5浅：不加，明天再测；连着3天都在这档，补1次首剂量。
   - NH3 0色、原水到顶、稀释样比0.5浅（低于3）：补1次首剂量（1 mg氮/L）。
   - NH3 0色、稀释样也到顶（3或更高）：不加，等NO2降下来。
   - 沙里发NH3 >2（不是刚加完检查量），且稀释样（1份缸水加2份RO，读数×3）也>2（6以上，约5 mg氮/L）：不加，换1/3～1/2同温同盐海水，再测（BRS/DrTim：全程不超过5 ppm氮）。NO2按上面补喂最多到约2 mg氮/L，到不了5，不用另测。
   - 每周测两次KH和pH：每投1 mg氮/L约消耗0.4 dKH，整个养水期常累计掉4 dKH以上；KH低于6 dKH或pH低于7.8，换25%～30%同温同盐海水再测。
   - 补喂门槛（NH3 0色、NO2低于3补1 mg氮/L）是本缸在BRS/DrTim做法上的调整；原文是NH3和NO2都低于0.2再加2 ppm，并提醒天天加氯化铵水会让NO2过高、拖慢养水。[8](https://www.drtimsaquatics.com/resources/library/quick-guide-to-fishless-cycling-with-one-and-only/)[9](https://www.drtimsaquatics.com/blog/ammonium-chloride-1-drop-or-4-drops/)
5. 沙里发NH3 0色、益尔NO2原水≤0.1后，再加一次已知量的NH3，24小时后复测。BRS和DrTim都用**2 mg/LNH3-N**作检查量，24小时后NH3-N和亚硝酸氮都低于0.2 mg/L算通过。[22](https://www.bulkreefsupply.com/content/post/brstv-product-spotlight-dr-tims-one-and-only)[8](https://www.drtimsaquatics.com/resources/library/quick-guide-to-fishless-cycling-with-one-and-only/)
   - **本缸做法：**用2 mg氮/L检查量（主缸V×0.764 g氯化铵水，检疫桶15.3 g），24小时后沙里发NH3 0色且益尔NO2原水≤0.1算通过一轮；连续通过两轮才算养成。0.5是色卡顶格分不清上限，所以用下一格0.1；0.1不论按亚硝酸根还是按氮标都低于0.2 mg氮/L。没通过就回到第4步按读数补喂，不连续叠加检查量。
6. 通过后测NO3（沙里发NO3色卡0、2、5、10、25、50、100，从上往下看）：10或以下换约10%；25换约1/4；50换一半、次日复测；100换一半、次日复测再换。复测温盐，再分批放第一批动物。[22](https://www.bulkreefsupply.com/content/post/brstv-product-spotlight-dr-tims-one-and-only)
7. 放入任何动物后停加氯化铵，由排泄和喂食提供氮源。新缸缓慢加鱼；NH3反弹时减少投喂、检查过滤并换水。[8](https://www.drtimsaquatics.com/resources/library/quick-guide-to-fishless-cycling-with-one-and-only/)[5](https://ask.ifas.ufl.edu/publication/FA031/pdf)

**本缸配法（称重，不量毫升）：**主缸和检疫桶用同一瓶：氯化铵2.0 g加RO水到总重200.0 g，装有盖瓶贴“氯化铵水1%　勿饮”，用前摇匀。每1 L实际水量，1 mg氮/L称0.382 g溶液，2 mg氮/L称0.764 g。检疫桶20 L：首剂和补喂7.6 g、检查15.3 g；主缸V＝150 L：首剂和补喂57.3 g、检查114.6 g。只用一种浓度，免得拿错瓶。

**试剂单位换算：**0.2 mg/LNO2-N约等于0.66 mg/L亚硝酸根（NO2⁻）；0.2 mg/LNH3-N约等于0.24 mg/L NH3或0.26 mg/L NH4⁺。色卡最低一档分辨不出0.2时，记下它的可检出范围，入鱼后继续测NH3；色卡最高一档太低时，用RO水按比例稀释样品再测、读数乘回倍数。沙里发NH3测的是NH3＋NH4⁺总量，色卡最浅格就是0。[9](https://www.drtimsaquatics.com/blog/ammonium-chloride-1-drop-or-4-drops/)

## 活石怎么处理

- 先把设备试好，再用配好的海水清理、漂洗活石，挑出运输中死亡的生物和不想要的搭载生物。[2](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=644885&page=1#pid6673260)
- “煮石”指在避光的海水中循环处理活石，不是加热煮沸。处理完仍按上面的NH3和NO2检测，少量分批放生物。[3](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=669281&page=1#pid6836100)[4](https://ask.ifas.ufl.edu/publication/FA099/pdf)
- 旧帖的“爆藻养水”主张长时间开灯，看藻相变绿或藻白化再结束。无动物的干石缸直接用上面的NH3负荷测试判断，不用把灯开到每天18–24小时，也不用放鱼测试。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=94002&page=1#pid1188796)[10](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=617341&page=1#pid6422944)[11](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=625773&page=1#pid6500086)
- 死石开缸过早放鱼会造成损失，原帖作者也有亲身例子。活石和死石都先测NH3和NO2，再逐步加负荷。原帖把草皮（绿星水螅）归为LPS，它属于软珊瑚。[17](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394715)[18](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394714)[21](https://tidalgardens.com/stock-green-star-polyps.html)
- 有鱼后不再加氯化铵喂菌。通过后一周内没放动物不用补；超过一周，每2～3天补一次1 mg氮/L，放动物前1～2天按第5步再做一轮24小时检查。已经有动物时不加氯化铵，按新增生物分批放、每天测NH3。[4](https://ask.ifas.ufl.edu/publication/FA099/pdf)[5](https://ask.ifas.ufl.edu/publication/FA031/pdf)
