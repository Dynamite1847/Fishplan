# 滤棉、生物滤材与活性炭

**结论：**物理滤棉放在容易拿取的位置，及时清洗或更换；生物滤材保持过水，分批清洗；活性炭按需使用、定期更换。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=67256&page=1#pid814969)[2](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=602217&page=1#pid6316930)[3](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=643902&page=1#pid6665122)

## 具体怎么做

1. **摆放顺序：**来水依次经过可取出的粗棉、细棉；生物滤材放在棉后持续过水的位置；炭袋放在棉后、水能穿过袋子的位置。蛋分与滤材的先后按底缸隔板安排。[2](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=602217&page=1#pid6316930)[9](https://www.bulkreefsupply.com/content/post/a-beginners-guide-to-filter-media-and-how-to-use-it)
2. **处理滤棉：**每天看一次污物和水位，发褐、积便或水流被堵就处理。粗孔海绵冲洗后可重复用；羊绒棉等细棉直接换新。BRS建议细棉约3–5天检查更换，脏得快就提前换。确认堵棉时水能经安全旁路回到底缸。[5](https://ask.ifas.ufl.edu/publication/4H433/pdf)[9](https://www.bulkreefsupply.com/content/post/a-beginners-guide-to-filter-media-and-how-to-use-it)
3. **每周排污：**检查岩石下和底缸有没有积便，换水时用细管吸掉。滤棉拦住的残饵和颗粒仍在系统里，取出清洗才算移走。干湿板和滤袋都能用，前提是水能穿过材料，堵塞后有安全溢流路径。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=67256&page=1#pid814969)[13](https://assets.speakcdn.com/assets/2332/1_rescue_coral_holding_facility_and_propagation_facility_documents_v10-31-24.pdf)[14](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=35410&page=1#pid394712)
4. **处理砖、陶瓷环：**装在能过水的网篮里，不压实。脏时在换出的旧海水里轻晃，去掉表面沉积。分批清理，保留大部分成熟表面。[6](https://www.merckvetmanual.com/all-other-pets/fish/routine-health-care-of-fish)
5. **用活性炭：**按包装建议量装入细网滤袋，扎紧，用纯水冲到流出的水基本清澈。把袋子摊薄，放在滤棉之后、水能流过的地方。取出时托住袋子，避免炭粉散进缸里。[3](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=643902&page=1#pid6665122)[7](https://www.bulkreefsupply.com/content/post/how-to-use-brs-carbon)

**活性炭用量例子：**总水量150 L，用BRS ROX 0.8活性炭，按1汤匙／10美制加仑起步，约用**60 mL**，厂家建议1–2周更换。Seachem MatrixCarbon标注250 mL用于400 L，150 L约用**94 mL**，更换周期按它自己的说明。两个产品的用量和周期分别对应各自产品。[7](https://www.bulkreefsupply.com/content/post/how-to-use-brs-carbon)[8](https://seachem.com/matrixcarbon.php)

**本缸做法：**活性炭（品牌未报）按本品说明及实际水量用，不套用上面两个产品的量；无鱼养水期不放，首批动物前完成换水后启用。养水期出现明显黄水、异味可提前放：冲净炭粉，薄摊在左前格滤棉后、上层砖上方，用开孔网格托起约10 mm，对准棉后落水。

## 水从滤材旁边走，怎么办

1. 打开底缸灯，在正常流量下看：滤棉是否基本被润湿，棉后的水是否持续经过砖或炭袋。部分绕流是常见的；滤材持续浸水、周围有水交换，就仍在起作用。[9](https://www.bulkreefsupply.com/content/post/a-beginners-guide-to-filter-media-and-how-to-use-it)[10](https://www.bulkreefsupply.com/content/post/md-filter-media-cup-what-you-need-to-know)
2. 水从一侧快速直走、炭袋几乎接触不到水时，先把炭袋摊薄，移到棉后明显的水流路径上。仍然绕流，就用**可拆的实心侧挡板**把部分水引向炭袋和砖。原有过水口和应急排水保持畅通。[10](https://www.bulkreefsupply.com/content/post/md-filter-media-cup-what-you-need-to-know)[11](https://seachem.com/matrix.php)
3. 调整后用正常泵档观察水位，再模拟滤棉堵塞，确认水从高处溢回底缸、不溢到缸外。换回干净滤棉后再看回水格水位。水位接近缸沿时，立刻撤去或降低挡板。

## 补充要点

- 硝化微生物附着在石头、滤材和其他湿表面上，需要持续供氧和水流。旧帖说“所有菌不在水中”“水泵杀死大多数菌”，不要据此决定是否投菌。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=67256&page=1#pid814969)[4](https://ask.ifas.ufl.edu/publication/FA031/pdf)
- 活性炭吸附部分溶解性物质，硝化由生物滤材承担。遇到异常污染，先找来源、换水并加强供氧。[3](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=643902&page=1#pid6665122)[4](https://ask.ifas.ufl.edu/publication/FA031/pdf)
- **人工滤材要不要加：**已有足量活石的系统可以不加人工砖（2019年CMF文章）；Seachem宣传其多孔滤材兼有硝化和反硝化作用。干石缸已有的砖可继续作为硝化附着面；NO3是否需要再降，看水质趋势、换水和藻区效果。[12](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=642949&page=1#pid6658267)[11](https://seachem.com/matrix.php)
