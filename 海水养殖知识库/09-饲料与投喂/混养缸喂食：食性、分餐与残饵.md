# 混养缸喂食：食性、分餐与残饵

**结论：**按每条鱼的食性和体型配粮；少量分次、换位置投喂，胆小和底栖的鱼单独点喂；看每条鱼是否吞下，再按体态、残饵和水质调整。冻饵一次只取当餐的量，解冻后分份投喂。[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=659149&page=1#pid6767251)[2](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=153573&page=1#pid1958823)[3](https://www.fishbase.se/summary/paracanthurus-hepatus)[10](https://www.bulkreefsupply.com/content/post/tips-and-trick-for-feeding-saltwater-fish-beginners-guide-ep-37)

## 具体怎么做

1. **先列每条鱼的菜单：**杂食鱼用海水鱼颗粒或冻饵作主食；偏植食的鱼加海藻饲料；底栖鱼用能沉底、适口的颗粒或切碎的冻饵。倒吊按物种区分：蓝吊以浮游动物为主，食性详见[选鱼](../06-%E6%B5%B7%E6%B0%B4%E9%B1%BC%E9%A5%B2%E5%85%BB%E4%B8%8E%E6%B7%B7%E5%85%BB/%E9%80%89%E9%B1%BC%E5%85%88%E7%9C%8B%E6%88%90%E4%BD%93%E3%80%81%E9%A3%9F%E6%80%A7%E5%92%8C%E6%80%A7%E6%A0%BC.md)。[2](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=153573&page=1#pid1958823)[3](https://www.fishbase.se/summary/paracanthurus-hepatus)
2. **频次：**常见混养鱼从每天1–2次、每次少量起步；花倒吊、海金鱼和幼鱼按物种调整频次。不要按旧帖“新缸三天喂一次”的做法让鱼持续消瘦。本缸首批4条从早晚2次起，鱼齐后早、中、晚3次小餐，见[生物与喂食](../../04-生物与喂食.md#同缸日常投喂)。[5](https://www.merckvetmanual.com/management-and-nutrition/nutrition-exotic-and-zoo-animals/nutrition-in-fish)[1](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=659149&page=1#pid6767251)
3. **份量：**颗粒粮以约2分钟内吃完为一次的量（高够力颗粒说明）。高够力冻糠虾说明建议单次不超过鱼30–45秒能吃完的量。第一次先投少量，吃完再加，记下各鱼吃到多少，第二天按前次增减。[7](https://www.hikariusa.com/docs/Hikari_Tropical_Catalog_2018.pdf)[11](https://www.hikariusa.com/frozen_folder/mysis_shrimp.html)
4. **分餐：**先在鱼活跃处少量撒食，确认都开始吃，再补第二小撮。抢食鱼被引开后，在慢鱼常待的位置投第二份。[5](https://www.merckvetmanual.com/management-and-nutrition/nutrition-exotic-and-zoo-animals/nutrition-in-fish)[6](https://www.aquariumofpacific.org/downloads/CURRENTS_SPRING_09.pdf)[10](https://www.bulkreefsupply.com/content/post/tips-and-trick-for-feeding-saltwater-fish-beginners-guide-ep-37)
5. **点喂慢鱼和底栖鱼：**用长滴管或接软管的注射器，把食物缓慢送到洞口。管口保持在水中，不碰鱼。确认鱼吞下再结束。[10](https://www.bulkreefsupply.com/content/post/tips-and-trick-for-feeding-saltwater-fish-beginners-guide-ep-37)
6. **收尾：**吸走剩饵，洗净器具。为喂食调慢或暂停了泵，设手机提醒，喂完马上恢复。持续拒食、消瘦或NH3上升时另行排查喂食量和生物过滤。[4](https://ask.ifas.ufl.edu/publication/FA031/pdf)[5](https://www.merckvetmanual.com/management-and-nutrition/nutrition-exotic-and-zoo-animals/nutrition-in-fish)

## 冻糠虾怎么喂

1. 从冷冻板上掰一小块，其余马上放回冷冻室。两条小鱼第一次每条先试约**1–2只适口大小的糠虾**；幼鱼嘴小就剪碎。之后按体型和胃口增减。本缸首批4条起步每天冻糠虾约0.5 g、颗粒约0.1 g，分2～3餐，用0.1 g秤称。
2. 把当餐的量放进干净小杯，加少量缸水轻轻搅散，完全解冻后分成两三小份。有的产品允许整块直投，但先解冻更好控制份量。[12](https://www.bulkreefsupply.com/content/post/defrosting-frozen-mysis-shrimp)[13](https://www.oceannutrition.eu/faq/)
3. 少量喂食时可以连解冻液一起投；营养盐偏高时（沙里发NO3高于20 mg/L，或PO4高于0.10 mg/L），用细网沥掉解冻液再喂。冲洗会损失部分细小食物。控制投喂量、清理残饵对营养盐的影响更大。[12](https://www.bulkreefsupply.com/content/post/defrosting-frozen-mysis-shrimp)[14](https://www.reef2reef.com/ams/phosphate-in-the-reef-aquarium.9/)
4. 解冻过的食物不再冻回原板。有异味、变质或运输中化冻的饵料丢掉。普通成鱼可与完整配合颗粒粮交替喂。

## 鱼粪和残饵

鱼粪和残饵都是有机物来源。不用追着每一点粪便清理，定期清除堆积处、及时换脏滤棉即可。[8](https://www.cmfish.com/bbs/forum.php?mod=viewthread&tid=644884&page=1#pid6673250)[9](https://www.fisheries.noaa.gov/aquaculture/nutrient-impacts-finfish-aquaculture)
