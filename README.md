# Fishplan

上海客厅 DIY 底滤海缸的设计、询价与搭建记录。

**当前阶段：确定设计流程，下一步确认需求。尚未完成加工设计，也未下单采购。**

## 从这里继续

1. 阅读 [交接说明](HANDOFF.md)，了解已确认的决定、未定事项和下一步。
2. 一起完善 [需求清单](docs/需求清单.md)，先处理影响整体布局的问题。
3. 按 [项目推进计划](DIY底滤海缸-项目推进计划.md) 逐步完成系统结构、设备空间、缸架联合布局和详细设计。

## 当前方向

- 主缸长度不超过600mm，希望长期使用。
- 定做玻璃主缸和底缸，自组铝型材架及管路。
- 生物方向为小丑鱼、珊瑚，未来考虑海葵。
- 接受二手设备；原预算约3000元，目前允许适当调整。
- 重视客厅噪声，预留未来冷却设备和防猫结构。

尺寸、型材、设备型号和价格尚未定稿。历史估算不能作为商家报价或采购依据。

## 在另一台电脑上继续

首次使用：

```sh
git clone https://github.com/Dynamite1847/Fishplan.git
cd Fishplan
```

已有工作副本时，在本地修改已妥善保存后运行：

```sh
git pull --ff-only
```

GitHub登录凭据不会随仓库同步，新电脑需要单独配置认证。
