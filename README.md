## 本版方向

- 助手建议优先核验600×450×400主缸、匹配长深约800高铝架；600×400保留备选。用户偏好深400，必要时可扩到约450，最终深高未冻结。
- 后左缸内溢流，主下水与独立应急下水穿底进入柜内底缸，回水单独返回。
- 主缸铺砂、活石，一只可调造浪列入首批设备；按一对小丑规划，珊瑚及海葵分批进入。
- 初期开放，后装可拆面板；顶部预留灯、风扇、喂食和猫盖接口。
- 维护以正面、左侧操作为主；手动搬水、临时从主缸抽旧水。
- 木地板及楼下邻居、近卧室及留宿场景，防漏和噪声均需正式验收。
- 固定承压底座为主，可收回轮为另核验的检修选项，不把推满水缸作为抢险方法。

设备候选尚未核实完整规格，预算3050～5250元为规划区间，**不是实时淘宝报价**；冷水机、未来面板、轮子及后续珊瑚海葵另计。收尾恢复访问后已补查四家品牌资料；设备参数仍有未闭合项，证据状态见[品牌参考](research/品牌结构参考与取舍.md)。

## 在另一台电脑继续

首次使用：

```sh
git clone https://github.com/Dynamite1847/Fishplan.git
cd Fishplan
```

已有工作副本，先妥善保存本地修改，再运行：

```sh
git pull --ff-only
```

GitHub认证不会随仓库同步，新电脑需要单独配置。不要把凭据或授权验证码写进仓库。

[v0.1总体布局](design/总体布局-v0.1.md)仅作迭代追溯；旧京东、淘宝背滤清单在[archive](archive/README.md)，不作为本轮采购或加工依据。
