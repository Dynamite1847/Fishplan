# 60cm DIY底滤海缸

上海客厅里的一缸60cm海水缸：铝型材架，上面主缸、下面底滤，管路自己设计、自己接。这里记下配置、做法和每天的养缸过程，给想自己搭底滤缸的人参考。

2026-11-12注水开缸，11-20起放清洁队，11-21首批公子小丑一对开始检疫。最新进度看[待办](01-待办.md)和[日记](06-日记/)。

## 水怎么走

主缸 → 背包 → 主下水 → 底缸左后接水格 → 左前干湿格（羊绒棉 → 黑粗棉 → 棉下细菌屋）→ 中间蛋分格（蛋分、加热棒、培菌砖）→ 右前藻格（钢丝藻）→ 右后回水格（主泵）→ 两个回水嘴回主缸。

应急下水平时不过水，主排堵了才走，也落在左后格。滤棉堵了，水有路越过棉托直接回中间格。

## 怎么做的

1. **设计**：主缸、底缸、架子、开孔和管路放在一起定，用FreeCAD建模，出三视图和3D装配页。
2. **架子和承托**：框梁共面，上面整块硬板，再铺整张缸垫，最后放缸；软垫不跨空，不只垫四角。
3. **管路**：管夹直接固定在型材槽上；整套先不上胶试拼，再分段粘接，等胶干透。
4. **试水**：用自来水试漏，同时试停泵回流、应急下水、堵棉旁通和止回阀失效；试完全部排掉。
5. **造景、注水**：空缸摆石铺砂，加RO并按桶计量，在底缸化盐到比重1.025、约26℃。
6. **无鱼养水**：硝化细菌加1%氯化铵水作氨源，每天测NH3和NO2；NH3不显色、NO2≤0.1就放第一批动物。
7. **清洁队先进**：螺、海胆、清洁虾和钢丝藻直接进主缸，不检疫。
8. **鱼全部检疫**：25L桶每轮1～2条，Cupramine铜0.5mg/L连续14天（蓝吊30天），期间吡喹酮两次，相隔7天；合格后只把鱼网进主缸，不带桶水。
9. **之后**：放鱼后每周换20L；鱼分批进；珊瑚等温盐、KH和氮磷连续稳定两周后再上。

每一步的操作和数值见[03安装与开缸](03-安装与开缸.md)，检疫和用药见[04生物与喂食](04-生物与喂食.md#检疫路线)。

## 生物

- **清洁队**：织纹螺、紫底星螺、金环宝螺、蓝礼服海胆、医生虾、火焰虾，一只红纹枪虾等着配黄守望。
- **鱼（计划约10条，6轮检疫）**：公子小丑一对（首批）、黄守望＋雷达、柠檬蟋蟀＋蓝鬼王、火箭吊、蓝吊、小型神仙1条、黄尾蓝魔。两条吊按过渡养，长大转出。鱼单还在调整，以[05生物配置](05-缸体与设备方案.md#生物配置)为准。
- **喂食**：每天早晚两次。
- **珊瑚**：先软体（菇、纽扣、皮革），再考虑好养的LPS；不养SPS。
